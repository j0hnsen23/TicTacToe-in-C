# TicTacToe in C

A school project focused on developing a fully functional Tic Tac Toe game using structured programming, functions, and custom variables.
---

## Features

- Two-player local gameplay  
- Turn-based system with clear prompts  
- Input validation to prevent invalid or non-numeric input  
- Automatic win detection (rows, columns, diagonals)  
- Draw detection when the board is full  
- Replay option after each completed game  
- Clean and readable console output  
- Structured and modular code using functions  

---

## How It Works

- The game initializes an empty 3×3 board  
- Players enter their names before the game starts  
- Player 1 uses **X**, Player 2 uses **O**  
- Players take turns choosing a position (1–9)  
- Each move is validated to ensure it is legal  
- After every move:
  - The board is updated  
  - The game checks for a winner  
- The game ends when:
  - A player gets three in a row  
  - Or all spaces are filled (draw)  
- Players are then asked if they want to play again  

---

## Technologies Used

- **C (C99 standard)**
- Standard libraries:
  - `stdio.h` — input/output
  - `stdbool.h` — boolean logic
  - `ctype.h` — character handling
  - `string.h` — string manipulation
